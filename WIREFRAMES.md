## Design Notes

| Element | Specification |
|---------|---------------|
| **Theme** | Dark mode default, light mode toggle |
| **Primary Color** | Cyan/Teal (#06b6d4) |
| **Background** | Dark navy (#0f172a) |
| **Cards** | Glassmorphism with subtle border |
| **Typography** | Large fonts for TV display readability |
| **Charts** | Simple bar/line, high contrast colors |
| **Spacing** | Generous padding, clear visual hierarchy |
